# Semantic UV Organizer — 日本語設計仕様書

版: 1.2 / 作成日: 2026-11-10 / 状態: 実装に用いる確定仕様

関連文書: [実装指示書](IMPLEMENTATION_GUIDE.md)

## 1. 目的と適用範囲

Blender向け自動UV展開アドオンを、幾何解析、ルールベース評価、反復最適化で実現する。展開歪みだけでなく、人間がテクスチャを描き、部品を見分け、修正しやすい配置を重視する。「Semantic」はマテリアル、接続、近接、形状類似性、対称性に基づく分類を意味し、学習モデルによる意味推定は行わない。

新規生成、既存UV改善、選択面の部分再展開を正式機能とする。本書はアドオン自体の実装・動作検証の完了を表すものではない。

初期実装の基準は既定のBlender 4.5 LTS、Python同梱版、bpy・bmesh・mathutilsとする。Windows、Linux、macOSで検証し、Blender 5.xは別途互換検証後に対応を宣言する。GPU、外部通信、外部AI、学習済み重み、学習データを要求しない。Extension形式で配布する。

対象外: マテリアル統合、テクスチャベイク、画像解析、Shader Nodeの一般評価、トポロジー修復、モディファイア適用。共通UV配置は共通テクスチャへのマテリアル変更を意味しない。

## 2. 要件と優先順位

### 2.1 基本原則

| ID | 必須要件 |
|---|---|
| R-001 | 機械学習、ニューラルネットワーク、外部AI APIを使用しない |
| R-002 | 元のメッシュ、全既存UV、シーム、マテリアルを保護する。結果は新規UVマップへ出力 |
| R-003 | マテリアル境界は有力なシーム候補だが、常に分割する義務はない |
| R-004 | キャラクター、建築、機械、有機形状などを扱う汎用設計 |
| R-005 | オフラインで完結 |
| R-006 | 同一入力・設定・環境・シード・探索予算で再現可能 |
| R-007 | 非多様体、退化、制約衝突、資源不足等では安全に失敗し、問題箇所と理由を報告 |
| R-008 | Apply前のバックアップ、全対象の原子的確定、失敗時ロールバック、Apply後Restoreを実装 |

|---|---|---|
| R-101 | 複数オブジェクト共通UV | 選択した複数Mesh Objectを結合せず共通UV空間へ配置し、オブジェクト間の衝突も検査 |
| R-102 | 新規生成／既存改善 | 切替可能。改善では実際のUV接続、方向、相対位置を初期解として利用 |
| R-103 | テクセル密度 | ワールド空間の3D表面積に比例してUV面積を配分し、複数オブジェクトで統一 |
| R-104 | 可読性と充填効率 | グループ近接、方向統一と領域利用を両立 |
| R-105 | 高速処理と局所探索 | 高速な初期解を作り、歪み等の問題Chartに限定して追加探索 |

### 2.3 部分再展開の正式要件

| ID | 要件 |
|---|---|
| R-201 | 各対象オブジェクトの選択面のみを再展開対象とし、選択を勝手に拡張しない |
| R-202 | 面コーナー単位の境界固定と、境界を保った局所再展開を提供 |
| R-203 | 出力UVの未選択面コーナーは入力UVと完全一致。元UVマップは全コーナー不変 |
| R-204 | 選択側を切り離す明示モードでは、未選択UVを障害物として空き領域に再配置 |
| R-205 | 失敗、取消、制約違反、確定途中の異常は対象全体をロールバック |
| R-206 | 複数オブジェクトの選択面を一括処理し、固定障害物・配置候補を共通空間で管理 |

安全性・未選択不変・ハード制約・正しいUVを、密度、可読性、充填率より優先する。ソフト目的の改善でハード制約を破ってはならない。

## 3. 入力、モード、出力

設定を二軸で持つ。`scope=ALL_FACES | SELECTED_FACES`、`uv_mode=GENERATE | IMPROVE`。SELECTED_FACESでは入力UVを必須とし、その複製を土台に選択部分だけを生成または改善する。入力UVがない場合は全体生成を案内して停止する。

対象は編集可能な選択Mesh Object。非Meshは対象外として一覧表示する。隠れた面は部分対象に含めず、未選択障害物として扱う。面選択を正とし、UV Editorのコーナー選択から暗黙変換しない。複数オブジェクトEdit Modeの面選択を確定時に取得する。選択面ゼロのオブジェクトは書込対象外だが、選択された共通UVセット内の既存UVは障害物として含める。

入力UVはオブジェクトごとに明示選択し、初期値はアクティブUV。全体生成ではUVなしも許可する。結果は衝突しない新規名（例: SUO_Result_001）を各変更対象に生成する。既存UV、既存のアクティブ／レンダーUV設定は自動で切り替えない。プレビューは作業コピーで表示する。新規UVを使用するための切替は別の明示操作とする。

共有Mesh Dataは検出する。複数インスタンスのUVを独立に変更できないため、独立化を明示許可した場合のみ作業・確定計画に組み込む。非対象ユーザーへの影響も検出し、無断独立化、無断共有書換えは禁止する。リンク、読取専用、出力レイヤー追加不能は事前停止する。

対象はベースメッシュ。モディファイア評価後のトポロジーをベースメッシュへ推測対応しない。オブジェクト変換を適用せず、ワールド座標へ変換した三角形から面積を計算する。非一様・負スケールも面積と向きを明確に処理し、ゼロスケールは停止する。

## 4. 内部データモデルと構成

IDは処理スナップショット内で有効な`(object_key, local_id)`。UVは頂点ではなく`(object_key, face_id, corner_id)`で識別する。同じ3D頂点でもUVシームの両側は異なるコーナーである。

| データ | 主な内容 |
|---|---|
| InputSnapshot | オブジェクト／Mesh対応、変換、トポロジー、全UV・pin・選択属性、シーム、マテリアル参照、UI状態、入力ハッシュ |
| EdgeFeatures | 接続面、長さ、二面角、曲率、マテリアル境界、色差、既存シーム、制約、候補スコア |
| UVChart | 面集合、境界、ワールド面積、歪み、グループ |
| UVIsland | 全コーナー座標、輪郭、面積、方向、ロック、タイル、由来 |
| UVGroup | 部品類似性、マテリアル、対称関係、方向、配置優先度 |
| PartialScope | 選択面、未選択コーナー、境界両側コーナー、pin、連結成分、配置モード |
| LayoutDomain | 許可タイル、タイル解像度、固定障害物、余白、密度基準 |
| ResultPlan | 全対象の出力UV、候補シーム、品質、警告、スナップショット識別子 |
| TransactionRecord | 変更前後ハッシュ、作成資源、参照変更、復元データ、状態 |

処理層は`core`、`blender`アダプター、`analysis`、`seams`、`unwrap`、`partial`、`layout`、`validation`、`persistence`、`ui`へ分離する。解析層に長寿命のBlenderデータ参照を持たせない。

## 5. 解析、シーム、展開

接続成分をDFS等で抽出し、二面角、曲率、マテリアル境界、面積、輪郭、主軸、アスペクト比、曲率分布から特徴量を生成する。色は静的に取得可能なBase ColorのOKLab色差を補助利用し、複雑なノードは「不明」とする。対称性は初期版ではローカルX/Y/Z鏡映を位置と面構造で確認し、信頼度不足なら適用しない。

シーム候補は正規化された二面角、マテリアル境界、凹凸・くびれ、幾何学的な目立ちにくさの近似で順位付けする。ビューに依存した曖昧な可視性推定は必須にしない。展開後に歪み、シーム長、アイランド数、細長さ、マテリアル分割の目的関数で再評価する。

エッジ制約はAUTO、PREFER、REQUIRE、AVOID、FORBID。REQUIRE/FORBIDはハード制約。保護では既存シームと保護された手動指定を維持する。優先では変更コストを課し、変更箇所と理由を表示する。無視では既存のソフトヒントを採点に用いないが、明示REQUIRE/FORBID、pin、部分境界、未選択不変は解除しない。矛盾するハード制約は停止する。

シーム生成は作業コピー上で実施する。新規UVに対応するシーム候補はメタデータ／オーバーレイで保持し、元メッシュのシームフラグは通常変更しない。実シームへの反映は明示操作でトランザクションとRestoreの対象にする。

Blender標準のAngle Based／Conformalを互換層経由で利用し、対応環境の挙動をテストする。改善モードは実際のUV連続性からアイランドを認識し、シームフラグとの不一致を警告する。正常なChartの形状・方向・相対配置を初期解として残し、問題領域の再展開を優先する。

局所探索はシーム追加・削除・移動・Chart統合。ハード制約内で、既存の正常解を悪化させない候補を選ぶ。全体に有効な初期解が得られなければ失敗。時間切れ時は完全検証済みの候補だけをプレビューできる。

## 6. 部分再展開の詳細

### 6.1 選択範囲と不変条件

1. 起動時に各対象の面選択を固定し、面集合Sと残りUを確定する。非連結のSを許可する。
2. 元UVを作業用・出力候補へ丸ごと複製する。書込可能なコーナー集合をSのコーナーに限定する。
3. Uに属する全コーナーは、座標だけでなくpin、UV選択属性も元値を保持する。共有頂点経由でSからUへ変更を伝播させない。
4. S/Uをまたぐエッジを選択境界とし、片面だけのメッシュ外周も境界として認識する。既存のUV分断を保持して境界対応を構成する。
5. ピン留めは選択内部でもハード制約。全体選択ではUが空でも、境界モードとpinの規則を守る。
6. 選択面ゼロは成功した変更として扱わず、説明付きno-op。面・頂点の追加削除、面順序変更は禁止。

### 6.2 境界固定モード: KEEP_BOUNDARY（既定）

S側の境界UVコーナーを元座標へ固定し、U側も完全固定する。内部コーナーのみを再計算する。既存UVが境界で連続なら連続性を維持し、もともと分断されていれば両側それぞれの元座標を維持する。固定境界と内部pinを展開バックエンドに渡し、返値を独立に検証する。

このモードでは対象を自由に移動・回転・拡縮して空き領域へ送らない。元の位置で改善可能な有効解がない場合は失敗する。選択領域と隣接Uが共有する正規の境界接触は許可するが、正の面積を持つ重複は禁止する。境界が全コーナーを固定する例では有効な変更がなくてもno-opとして説明する。

### 6.3 空き領域再配置モード: RELOCATE_SELECTED

ユーザーが明示選択した場合だけS側の選択境界固定を解除し、U側は固定のままSをUV上で切り離す。3Dメッシュは切断しない。切断境界を候補シームとして記録する。境界のFORBIDと衝突する場合は停止し、勝手に解除しない。

選択内部のpin／位置ロックは依然固定。固定点を動かす配置変換は禁止し、移動不能なら配置失敗とする。UIで「未選択側固定、選択側は境界分離」と明示し、境界両側を固定したまま自由に移動できると説明しない。

共通UVセットに含まれる全オブジェクトのUを固定障害物とする。Sの旧UVだけが占めていた領域は解放するが、Uと重なっていた領域は解放しない。先に配置したSも後続候補の障害物にする。非対象オブジェクトは自動的には含めず、占有を考慮したい場合は共通セットへ明示追加する。

各障害物を指定余白分だけ膨張させ、許可タイル内の空き領域へ候補を配置する。まず外接矩形で候補を絞り、三角形／輪郭の厳密な衝突判定で確定する。矩形近似だけで「空きなし」と断定せず、有限の輪郭配置探索を行う。探索で見つからない場合は「指定予算で実行可能解なし」と報告し、数学的な不存在を主張しない。

既定では指定密度を維持し、勝手な縮小、未選択UV移動、重複配置、追加タイル作成を行わない。解がなければロールバックし、タイル追加の明示指定、密度設定の変更、選択変更を案内する。KEEP_BOUNDARYから自動でこのモードへ切り替えない。

### 6.4 密度と既存の不正UV

KEEP_BOUNDARYでは境界固定が密度統一より優先され、達成できない密度偏差は警告・比較表示する。RELOCATE_SELECTEDでは指定密度、または固定Uの有効なアイランドから計算した面積加重の代表密度にSを合わせる。Uの密度は変更しない。全体一様化が不可能ならその理由を報告する。Uがなければ全体配置の密度決定に従う。

固定Uに既存の重複がある場合、独立配置要件を満たせないためApplyを拒否し、該当面の選択追加を案内する。固定Uの非有限座標や退化UVも停止対象とする。未選択部分を勝手に修復しない。

### 6.5 複数オブジェクト

選択範囲、境界、pinはオブジェクトごとに構築する。密度、障害物、許可タイル、衝突検査は共通で管理する。オブジェクトAの選択島とBの固定UV、A/B双方の選択島間の衝突を検査する。1対象でも制約違反なら一括失敗し、一部成功の確定は提供しない。

## 7. 意味的配置、密度、UDIM

同一マテリアル、接続・近接、対称関係を優先し、面積・周長・輪郭・曲率・トポロジー・主軸で類似候補を絞る。階層グループを生成し、グループ内を近接配置する。対称部品は隣接させても重ねない。方向は90度回転を優先し、主軸の信頼度が低ければ元方向を保つ。

全体配置はグループ領域割当、島配置、全体改善の順に行う。回転・移動・一様スケールを基本とし、鏡映や非一様スケールで面積を詰めない。

同一解像度では`k = A_uv / A_world`を全対象で統一する。必要な長さ倍率は`sqrt(k_target / k_current)`。面積比をそのまま長さ倍率にしない。解像度Rの正方形タイルでは密度は`R * sqrt(k)` px/ワールド単位。異なるタイル解像度は初期版では受け付けず、同一解像度を必須とする。

余白初期値は2048pxで8pxの島間距離、UV換算で8/2048。障害物と可動島の双方を膨張させる場合は各半分とし、二重加算しない。タイル端にも設定した余白を確保する。KEEP_BOUNDARYの連続境界は余白対象外。固定U同士の既存余白不足は保持・警告できるが、新規の正面積重複は一切許可しない。

単一タイルは1001の0〜1領域。UDIMはユーザー指定の許可タイルのみ使用し、`UDIM = 1001 + u + 10*v`（u=0〜9、v>=0）で管理する。島はタイル境界をまたがず、タイル番号と整数座標を対応させる。グループは可能な限り同一／近隣タイルへ配置する。部分処理の固定UVが許可外タイルにある場合は設定不整合として停止する。UDIM画像、マテリアルの作成や変更は行わない。

## 8. 品質判定と探索

有限座標、非退化、向きの整合、自己交差なし、全対象横断の正面積重複なし、許可領域内、ハード制約遵守をApplyの必須条件とする。負スケールを考慮した3D基準に対して向きを判定する。接する隣接三角形と重複を混同しない。

比較指標は平均／最大角度歪み、面積歪み、密度偏差、充填率、島数、シーム長、グループ分散、方向一致率。歪みはワールド空間で三角形化した対応から測り、充填率は許可タイル面積に対するUV三角形面積の和で計算する。グループ分散はグループ内重心距離の正規化値、方向一致は信頼できる対応島の角度差で計算し、人間の可読性の代理指標と明記する。

初期設定はBalanced。Texture Painting、Compact Packingも同じハード制約を持ち、ソフト重みだけを変える。既存改善ではハード有効な基準UVに対し、正規化した総合コストが悪化する候補を採用しない。基準UVが不正なら修復後のハード有効性を先に満たす。局所探索は固定候補数・反復数を主予算とし、時間上限は安全弁とする。時間による中断点が違う実行は同一結果保証の対象外とし、使用予算をログに残す。

数値許容差と密度目標の初期案は実装指示書に定義する。充填率、歪み、実時間の製品閾値は基準モデルによる測定後に固定し、未測定の性能保証は行わない。全モデルでSmart UV Projectに勝つことは要求しない。

## 9. 非破壊処理、復元、安全な失敗

状態遷移は`IDLE → SNAPSHOTTED → COMPUTING → VALIDATED → PREVIEW → COMMITTING → COMMITTED`。失敗／取消では`ROLLING_BACK → ROLLED_BACK`。Applyはユーザーの明示操作とする。

作業コピーで計算・検証し、元データはプレビューまで変更しない。Apply直前にトポロジー、入力UV、シーム、変換、選択、制約等の入力ハッシュを再確認する。不一致なら古い結果を確定せず再計算を要求する。全書込計画を検証し、復元データを確保してから出力レイヤー等を作成する。途中失敗なら作成物・参照変更を全対象で戻す。

スナップショットは全UV座標・属性、レイヤー名と順序、アクティブ／レンダー設定、シーム、変更する参照、オブジェクト・面選択、モードを含む。メッシュ形状、マテリアル参照等は不変検証の対象とする。結果の通常Applyは元UVとシームを変更しない。

Restoreは直近の本アドオンの確定を全対象まとめて取り消す。トポロジーと確定後データの指紋を検証し、ユーザーが後から変更した結果を無断上書きしない。不一致ではRestoreを拒否し、保存済みバックアップから別コピーへ回収する手段を案内する。復元情報は.blend保存時に保持できる管理データとして永続化し、明示削除まで残す。メモリ内のみのバックアップで再起動後の復元を保証しない。

Undoは補助であり、トランザクションとバックアップの代用にしない。プロセスクラッシュやOS障害に対する完全原子性は保証対象外で、保存済み.blendと永続バックアップからの回収範囲を明記する。ロールバック自体の異常は成功と表示せず、残存変更と回収方法を報告する。

## 10. UIとエラー

3D View／UV EditorにAnalyze、Generate、Preview、Compare、Apply、Cancel、Restoreを提供する。設定は対象一覧、入力UV、処理範囲、生成／改善、境界モード、シームモード、手動制約、密度、解像度、余白、単一／UDIM、許可タイル、探索予算、シード、可読性／充填重み。

部分処理では選択面数、固定面数、固定境界、分離境界、障害物、可動領域、密度達成可否を表示する。Apply前に出力先・対象・制約違反ゼロを表示する。境界解除、タイル追加、共有データ独立化は明示設定を必要とし、失敗回避のために自動変更しない。

エラーにはコード、対象Object／面／コーナー、失敗段階、変更有無、ロールバック状態、推奨対処を含む。例: INVALID_INPUT、CONSTRAINT_CONFLICT、NO_FEASIBLE_LAYOUT、STALE_INPUT、COMMIT_FAILED、RESTORE_CONFLICT。メモリ不足、取消、時間切れも正常な終了経路として扱う。

## 11. 受入と完成条件

実装指示書のT-101〜T-112、T-201〜T-216、T-301〜T-308をすべて実施し、必須テスト合格をリリース条件とする。部分再展開を将来拡張やオプションの未実装枠へ戻してはならない。

安全性テストは入力と出力のコーナー単位比較、全対象衝突検査、意図的な異常注入で確認する。性能閾値と品質閾値の未確定項目はベンチマーク時に数値を確定し、承認済みの試験条件・実測値を配布物に含める。未実装・未検証を実装済みと表示しない。
